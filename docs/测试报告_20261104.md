该页面包含五种题型、一个本地假 AI 接口和一个会记录点击次数的“学习通原生提交按钮”。本地 HTTP 服务返回 200，页面文件可以访问。

模拟页面继续用于五种题型、异常响应、任务控制和禁止自动提交的离线回归。

## 真实学习通页面只读验证（2026-11-06）

在用户亲自登录的独立临时 Edge 配置中，打开真实的学习通独立作业页面 `/mooc-ans/mooc2/work/dowork`。先完成只读页面结构验证；随后在用户明确指定的测试作业中，使用固定测试值 A 对第 1 题执行一次最小填写并立即刷新恢复。全程不读取或记录题干内容，不调用 DeepSeek，不点击暂存或提交。

验证结果：

1. 独立作业路由识别正确，悬浮面板正常显示。
2. 页面实际 17 道题，修复前因 `.TiMu` 总容器嵌套 `.questionLi` 被重复提取为 18 条；修复后为 17 条。
3. 修复后 17 个题目 ID 全部唯一，题号 1–17 连续，每题均提取到题干和 4 个选项。
4. 页面同时存在 `answertype...` 题型字段与 `answer...` 答案字段；修复前会把题型字段误判为已有答案，修复后 17 个空白答案字段均正确识别，已有答案误判数为 0。
5. 所有选项均能定位到可操作网页元素；第 1 题从空白变为已填写，真实 `answer...` 隐藏字段同步写入，证明选择事件能驱动当前学习通页面逻辑。
6. 页面立即刷新后，17 道题重新全部识别为空白，第 1 题答案字段长度恢复为 0，说明本次测试值没有被服务器自动保存。
7. 未使用真实 DeepSeek API Key，未产生 API 费用，未触发暂存或学习通提交路径。
